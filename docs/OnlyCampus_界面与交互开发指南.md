# OnlyCampus 界面与交互开发指南

版本：1.0  
更新日期：2026年11月1日  
适用成员：柏承辰、韩佳杞、赵庆浩  
适用范围：公共站点、个人中心，以及后续创作中心和管理后台的视觉衔接

本文规定团队后续开发时应遵循的界面逻辑和 UI 标准，以用户已确认的社交平台方向及当前实现为依据。具体业务、权限和数据库规则仍参考《OnlyCampus 详细开发文档》。本文与早期页面布局、目录或评论说明冲突时，以本文为准。尚未完成或待组员接入的内容在第12节列出，不视为已经验收通过。

## 1. 产品方向与内容优先级

OnlyCampus 意为“为校园而生的博客”。首页就是可以阅读和互动的帖子流。

- 布局参考 X 的固定导航和中栏内容切换，帖子保持作者与正文之间的清晰关系。
- 质感采用克制的色彩、细分隔线、自然间距和统一控件；保留当前浅色、绿色体系，不照搬参考截图的黑色主题。
- 标题、正文、作者和有效操作优先。删除宣传式首屏、英文小字标题、装饰性注释和重复的操作说明。
- 时间、表单错误、未登录提示和空状态属于有效信息，应保留；“删小字”不等于删除必要反馈。
- 不制作没有业务能力的关注、认证、转发、点赞或订阅入口，不填充虚构互动数字。
- 后台和编辑器可以使用表格、表单，但必须沿用相同颜色、字体、焦点和反馈规则。

## 2. 页面外壳与响应式布局

### 2.1 桌面端三栏

```text
固定左栏          中间内容栏                  右侧辅助栏
Logo             首页帖子流                  搜索框及历史下拉
首页             探索和搜索结果              浏览分类
探索             帖子详情                    成长专栏
收藏             个人主页
个人入口         收藏、登录
底部账号入口
```

- 所有公共站点页面使用同一个外壳。页面切换只更换中栏内容，不切换到早期的独立顶部导航页面。
- 左栏固定于视口，不能随中栏长内容滚走；底部账号入口保持可见。桌面左栏不直接固定在浏览器最左缘，应与居中的整体画布对齐。
- 中栏白底并带左右细边界，内容宽度受控，不因只剩一篇帖子而改变布局。
- 右侧搜索、分类和专栏属于辅助信息，内容不足时自然收缩，不造空卡片占位。
- 右栏不添加重复的网站宣传介绍或大段页脚。
- 当前画布最大宽度1320px，桌面列配置为240px／最多630px／240—320px，列间距30px；固定左栏实际内容宽度220px。后续优化不得造成横向溢出。

### 2.2 宽度变化

| 宽度 | 布局规则 |
| --- | --- |
| 大于1100px | 完整三栏，左栏显示图标和文字 |
| 901—1100px | 左栏缩为图标栏，中栏与右栏保留 |
| 721—900px | 左侧图标栏与中栏，隐藏右栏 |
| 不大于720px | 中栏占满屏宽，导航固定于底部，隐藏右栏及桌面左栏 |

公共样式仍有早期断点，后续整理时以本表作为统一目标。至少检查375或390px、768px、1440px。手机底部预留不小于导航高度的空间，最后一条内容和按钮必须可以完整滚到导航上方。

## 3. 导航与返回规则

| 入口 | 中栏显示 | 行为要求 |
| --- | --- | --- |
| 首页 | 最新／精选帖子流 | 最新按真实发布时间排序，精选来自后台真实标记 |
| 探索 | 搜索框和热搜榜 | 未输入关键词时不显示旧版筛选表单 |
| 提交搜索 | 搜索结果帖子流 | 保留输入词，条件写入URL，可刷新复现 |
| 收藏 | 本人收藏 | 游客先登录，成功后回到收藏页 |
| 个人入口、左下角账号 | 本人主页 | 未登录时先进入登录页 |
| 作者头像或昵称 | 对应作者主页 | 不把所有头像都指向当前用户 |
| 帖子标题或正文预览 | 帖子详情 | 在中栏打开，不另起网站布局 |

帖子详情左上角返回必须恢复进入该帖子的来源列表。来源包括首页、搜索结果、个人帖子、个人回复和收藏；保留来源URL及滚动位置。从首页进帖后，不能返回到热搜页。专栏上一篇／下一篇之间切换时继续保留最初来源，登录中转也不能覆盖来源。无可用来源时默认回首页。

当前来源信息保存在内存，完整刷新后不保证恢复之前的浏览链；不得宣称已经支持跨刷新或跨设备恢复。后续加入持久化时只保存站内路径，不允许任意外部跳转。

## 4. 搜索框 搜索历史与结果

### 4.1 搜索框位置

- 首页、详情和个人页：桌面右栏顶部显示搜索框。
- 探索及搜索结果页：中栏顶部显示搜索框，右栏原搜索框隐藏，分类和专栏整体上移。
- 手机：通过首页顶部搜索图标或底部探索入口进入中栏搜索。
- 同一屏幕不要同时出现两个输入同一关键词的搜索框。

### 4.2 历史下拉

使用 `SearchBox.vue`，不在不同页面复制各自的搜索逻辑。

1. 输入框获得焦点后，在其下方浮出“最近搜索”。
2. 搜索通过回车或搜索按钮提交，去掉首尾空白，关键词最多100字符。
3. 提交过的非空关键词进入历史，最近使用的在前，相同关键词去重，最多10条。
4. 点击历史项直接搜索；支持单条删除和清空全部历史。
5. 点击外部、焦点离开组件或按Esc后关闭下拉。
6. 没有历史时显示“暂无搜索记录”，不生成假历史。
7. 历史保存在当前浏览器的 `onlycampus.search` 中；不代表用户账户历史。存储不可用时搜索仍须正常工作。

### 4.3 热搜与结果

- 热搜由 `/api/trends` 返回，按关键词搜索请求累计次数排序，最多10条。目前没有独立用户去重、时间衰减和反刷机制，展示“次搜索”，不标成实时人数。
- 热搜没有数据时显示空状态，不硬编码热搜。
- 搜索结果直接复用帖子预览，顶部只有搜索框及“最新／最近更新”排序标签。
- 不再显示重复关键词输入框、分类标签排序组成的大表单，也不在结果前铺大块标题介绍。
- 分类或标签条件可通过URL保留，使用简洁的条件提示和“清除筛选”；它们不是帖子右上角标签。
- 无结果显示“没有找到相关帖子”和简短重试建议。结果不足一页时隐藏分页；有下一页时才允许继续翻页。
- `q`、`categoryId`、`tagId` 按AND组合，页码变化保留现有筛选条件；切换排序回第一页。

## 5. 帖子预览

首页、搜索结果和个人主页帖子列表必须复用 `PostPreview.vue`。

```text
头像  作者昵称 · 日期
      帖子标题
      正文摘要
      [有封面时展示封面]
      评论入口
```

- 头像和昵称进入作者主页；标题和摘要进入帖子详情；评论入口进入详情评论区。
- 不显示“阅读全文”文字或按钮，不显示右上角“课程学习／项目实践”等分类标签。
- 不在每条帖子外添加独立底色卡片、厚重阴影或装饰边框；用细横线分隔帖子。
- 不显示虚构评论、点赞、浏览量。没有真实封面时自然使用文字排版，不放破图占位。
- 日期为次要信息，不压过作者或正文。正文允许自然换行，长文本和链接不能撑破中栏。

## 6. 帖子详情

排列顺序固定为：

1. 固定顶部栏：返回、页面标题“帖子”，以及当前保留的专注阅读开关。
2. 作者头像和昵称。
3. 帖子标题和完整正文。
4. 发布时间。
5. 评论入口和收藏操作，同处正文下方操作栏。
6. 如属于公开专栏，显示有效的上一篇／下一篇。
7. 回复输入区及评论列表。

详情页不显示目录、目录抽屉或目录跟随高亮；不要按早期文档重新加入。正文仍允许二三级标题、代码和链接，移除目录不等于移除正文结构。标题后不重复渲染摘要和分类标签。

收藏状态来自接口；点击后局部更新按钮和选中样式，不重新加载整页、不改变阅读位置。未登录的收藏和回复应跳到登录并保留返回路径。专注阅读可以隐藏两侧区域，但必须保留退出入口。

## 7. 评论与楼内回复

### 7.1 显示与折叠

- 评论和回复都与中栏同为白底；禁止给楼内回复增加绿色、灰色等独立背景块。
- 顶层评论包含昵称、时间、正文及允许执行的操作。
- 楼内回复统一缩进约24px，使用轻分隔线，不随回复链无限加深缩进。
- 0条回复不显示展开入口；1条回复直接展示；多于1条默认折叠，显示“展开 N 条回复”，展开后显示“收起回复”。
- 用户刚发出的楼内回复所在讨论自动展开。通过个人回复记录定位时也应展开对应讨论。
- 用户只能删除自己的评论；不可见父评论只有在仍存在可见回复时保留占位，不返回原正文。
- 删除或隐藏的楼内回复不作为可见内容展示；分页数量与实际显示规则一致。

### 7.2 回复任意评论

- 顶层评论和可见楼内回复均可点击“回复”。输入框提示“回复 @昵称”，聚焦到输入区，并允许取消回复。
- 回复正文开头通过独立链接展示“@昵称”，链接到被回复人的主页；不要让用户手工拼接，也不要把服务端身份判断建立在正文中的`@`文本上。
- `parent_id` 固定保存顶层评论ID；`reply_to_id` 保存实际被回复评论ID，二者不能混为一谈。
- 新请求发送 `content` 和可选 `replyToId`；旧 `parentId` 仅为兼容入口。
- 服务端校验目标属于同一篇公开帖子且当前可见，通知发送给实际被回复人；自己回复自己不产生通知。
- 评论和通知在同一事务提交，失败时不显示假成功；前端保留输入供重试。
- 评论列表按顶层评论分页，楼内回复在同一讨论下按时间升序排列。当前楼内折叠仅控制界面显示，接口仍一次返回该讨论的可见回复，不能称为已经实现懒加载。

## 8. 个人主页

结构参考用户给出的个人页截图，保留当前浅色视觉：

```text
返回  昵称 / 帖子数
横幅
重叠头像                  本人可用的操作
昵称
简介
真实帖子数 / 公开专栏数 / 本人收藏入口
帖子       回复       专栏
对应标签内容
```

- 当前横幅为统一浅绿色，头像为昵称首字；真实头像、封面和资料编辑由相应模块接入后再展示。
- 本人和访客看到不同操作，访客不可获得退出他人账号、编辑他人资料或读取他人收藏的入口。
- “帖子”仅显示公开帖子，并支持分页。
- “回复”包含该用户对帖子发表的顶层评论，以及对其他评论的可见回复；只显示所属帖子仍公开的记录，支持分页。
- 回复记录包含内容、时间和来源帖子；有直接回复对象时显示“@昵称”。点击来源进入帖子、找到所在顶层评论页、展开讨论并定位该条回复。
- “专栏”显示该用户的有效公开专栏；正式专栏详情由韩佳杞负责对接。
- 不照抄参考图中尚未实现的认证、关注数、粉丝数、媒体、推荐关注等元素。
- 当前标签选择保存在页面状态，跨完整刷新恢复标签尚待完善；实现时建议使用URL，避免浏览器返回后显示错误标签。

## 9. 视觉规范

### 9.1 色彩

以下是当前页面使用的视觉值。新组件应统一引用共享CSS变量，后续整理旧CSS时以这些角色合并，不能继续堆叠新的近似色。

| 角色 | 颜色 |
| --- | --- |
| 页面外层底色 | `#F7F8F6` |
| 中栏、评论、回复底色 | `#FFFFFF` |
| 主文字 | `#202722` |
| 主操作与选中状态 | `#315C52` |
| 次要文字 | `#627166` |
| 常规分隔线 | `#E8ECE8` |
| 搜索框表面 | `#ECEFEB` |
| 个人主页横幅 | `#D6E3DC` |
| 占位头像 | `#BFCFC4` |

正文及普通小字对比度目标不低于4.5:1。颜色必须伴随文字或形状表达状态，不能只靠色差区分收藏、按钮禁用和错误。

### 9.2 字体与尺寸

- 正文使用系统无衬线字体栈：`-apple-system, BlinkMacSystemFont, Segoe UI, Microsoft YaHei, sans-serif`，不在不同模块重新引入装饰性中文字体。
- 主导航桌面约17px；中栏顶部标题20—21px；帖子预览标题桌面19px、手机17px；预览正文15px、手机14px；时间12—13px。
- 详情标题桌面22px、手机20px；正文桌面17px、手机16px，行高约1.85。
- 正文标题用字重和自然间距区分，不使用大面积渐变、描边或极大字号。
- 中栏常规水平留白24px，手机18px左右；帖子常规间距约20—25px。避免把整条帖子拉成巨大空白块。

### 9.3 控件与图标

- 搜索框约46—48px高，圆角约14px；辅助区圆角约16px；普通按钮8—10px；个人操作和主要回复按钮可以用胶囊形。
- 线条图标统一使用SVG，常用尺寸20—24px、描边1.6—1.8；不使用emoji或不同风格图标混搭。
- 可触控操作目标尽量达到44px；只有图标的按钮必须提供可访问名称。
- 点击反馈、悬停、禁用、选中和键盘焦点都要定义。不能移除焦点轮廓却不提供替代。
- 阴影只用于需要浮出的历史搜索等面板，正文和回复不增加卡片阴影。
- 动效控制在约150—250ms，尊重减少动画偏好；内容从默认可见状态开始，不依赖动画才出现。

## 10. 数据与异常反馈

- 列表首次加载使用无文字骨架屏，不显示“正在加载内容”；无数据用一句话说明，不填假内容。中栏内容切换采用约180ms淡入和轻微位移，两侧导航保持稳定；减少动画设置下停用过渡和骨架动画。
- 用户操作提交中禁用重复写入，成功只局部更新相关内容；失败显示可理解的原因并保留输入。
- 返回、翻页、排序和切换标签不得误把旧请求结果覆盖到新页面。
- 文章下架后公开详情不可读，收藏保留“文章已不可用”占位并允许取消，不能泄露私人标题及正文。
- 回复定位参数只影响当前公开帖子的评论，不得绕过权限读取其他帖子内容。
- ID保持字符串；时间由接口带时区返回，并按统一规则显示。时间格式和时区的最终统一需与另外两位成员共同验收。
- 不在产品页面展示数据库名、开发文件名、接口堆栈或技能配置。登录页仅显示用户操作文案，不展示演示凭据或内部开发说明。

前端技能用于辅助设计与检查，用户已确认的规则优先：不得因为技能推荐而重新加入宣传首屏、目录、分类角标或彩色回复背景。

## 12. 验收与当前差距

### 必查场景

- 从首页、搜索、个人帖子、个人回复和收藏进入详情，再返回正确来源。
- 左栏固定；移动端底部导航不挡住最后的内容和按钮。
- 探索页只有中栏搜索，右侧内容上移；搜索历史可用键盘、回车和Esc操作。
- 关键词、排序、翻页、无结果和清除筛选正确。
- 预览没有“阅读全文”和分类角标，正文可进入详情。
- 详情没有目录，收藏位于正文下方，评论或收藏不整页重载。
